# 使用指南

两种用法，任选其一（可共存，引擎同源、行为一致）：

| 方式 | 适合 | 安装成本 |
|---|---|---|
| **Tampermonkey 用户脚本** | 日常浏览器里零散投递 | 装个扩展 + 粘贴一份脚本 |
| **求职工作台（本地驱动）** | 批量投递：台账/盯梢/LLM 打标签 | 下载 release 或源码运行 |

---

## 一、Tampermonkey 用户脚本

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. Tampermonkey 面板 → 添加新脚本 → 全选删除模板 → 粘贴 [`autofill.user.js`](../autofill.user.js) 全文 → Ctrl+S
3. 任意网页右下角出现白瓷「AF」悬浮球即安装成功（脚本带 `@updateURL`，之后版本更新会自动提示）

**快捷方式**：双击 `tools\make-shortcut.vbs` 生成桌面快捷方式「网申快填」，按 **Ctrl+Alt+A** 直达网申页。

### 使用流程

1. 打开网申页面 → 点悬浮球 → 自动扫描（**只读，不写入**）
2. 核对清单：绿=高置信（默认勾选）· 琥珀=待确认 · 红=敏感（身份证等，默认跳过）· 灰=需人工（带「定位」）
3. 需要就在清单里直接改值 → 点「**执行填充 · 仅勾选项**」
4. **逐项核对，自己点提交** —— 脚本不会碰提交按钮

**快捷路径**：在页面上选择简历附件的那一刻，脚本自动扫描 + 按默认清单填充（设置里可关「上传附件后自动填充」；不读取文件内容）。

**快捷键**：`Alt+Shift+A` 唤起/收起面板 · `Alt+Shift+F` 扫描 · `Alt+Shift+D` 执行填充 · 分区式站点扫描=全程扫描。

### Profile（档案）

- 源文件：`profile/profile.example.json` → 复制为 `profile/profile.json` 后编辑（该文件已被 gitignore，不会提交）
- 生效方式：面板 → **Profile** Tab → 粘贴 JSON 或「选择文件」→ 校验并导入（存 Tampermonkey 存储，跨网站共享）
- **反向采集**：某个网站已经手工填得很全？Profile Tab →「采集本页已填 → Profile」一键读回——同名覆盖、缺段补建、岗位问答只记本站
- 导出：Profile Tab「复制导出」把浏览器里的数据存回文件
- 日期统一 `YYYY-MM`；*Full 后缀是含日完整日期；起止时间统一 `YYYY.MM-YYYY.MM`，脚本按页面控件自动换算格式
- 岗位变体：`variants`（后端/前端/管理）只覆盖差异字段，面板顶部下拉切换
- 自定义字段：`base.customFields` 加 `{ "path":"basic.xxx", "label":"显示名", "aliases":["别名"] }`
- 开放题模板：`base.openQuestions`，支持 `{{name}}/{{company}}/{{position}}` 占位符

### 自动学习（默认开，设置里可关）

你手动键入而 Profile 里没有的内容，静默写回本地 Profile——认识的字段写回对应字段，项目/实习按第 k 段写回，陌生标签建为自定义字段；验证码/搜索框/密码框永不学习。

### 本站问答记忆

"是否有亲属在本公司从业""是否有运营商经验"这类声明题**不进 Profile**，按网站域名分开记忆——同一家公司下次自动填，换一家第一次标出来请你定夺。设置 Tab 可清除。

### 开放题 Tab

Profile 里维护的开放题模板（自我介绍/为什么选我们/职业规划），一键「插入」到页面文本域或「复制」；配置 LLM 后还可「AI 生成初稿」（JD + 本机档案 → 定制初稿，不编造档案外事实）。

### iframe 表单（北森模式）

表单嵌在 iframe 里时，子框架字段自动并入清单（标签带 `[子框架·域名]` 前缀），填充逐行转发；子页面右下角另有一枚迷你 AF 按钮兜底。

### Debug 悬停模式（配合新平台）

设置 Tab 开启后，把鼠标悬停到任意控件上会显示该控件的 `KIND / LABEL 来源 / HIT 字典项 / 置信度`；「诊断报告」可生成全页结构报告——用于给新平台提适配（见 [platforms.md](platforms.md)）。

## 二、求职工作台（本地驱动 · Edge 专用）

### 启动

源码运行：

```bash
pip install -r driver/requirements.txt
python -m playwright install chromium
python driver/workbench.py     # 或双击 driver/start_af.bat
```

或下载 Release 里的 `AF-Fill-Workbench-*.zip`，双击「求职工作台.exe」。

- 工作台自动在求职 Edge 打开（`http://127.0.0.1:8790`），重复启动不会起第二份
- 数据全部在程序目录 `data\`（config / ledger / profile / watch / logs）
- 首次运行会拉起**专用 Edge 剖面**（`%USERPROFILE%\edge-af-profile`，与日常浏览隔离），在里面登录各招聘站一次即可
- 想用日常 Edge 的收藏/密码/登录态：设置页 →「从我的 Edge 导入」（需先完全退出日常 Edge；自动备份）

### 工作流

1. 任意职位页：左下角「+ 台账」chip（`Alt+Shift+C`）收录 → LLM 已配置时自动打标签
2. 工作台台账：勾选 →「批量打开」（错峰开页）→ 逐页核对填充 → 填充事件自动标「已填」→ 自己点提交 → 手动标「已投」
3. 状态机：收录 → 已打开 → 已填 → 已投 → 面试/挂

### LLM（可选）

工作台右侧或脚本设置里填 Base URL / API Key / 模型名（DeepSeek / Kimi / 通义 / 本地 Ollama 通吃）→「测试连通」。启用后获得三件事：

- **AI 扫描映射**：歧义选项消歧（如「全日制统招」↔「普通全日制」）+ 未命中字段映射档案键（如「技术博客」→ `basic.github`），防幻觉校验；`🤖` 标 + 默认勾选待核对
- **AI 复核**：扫描结果逐行语义复核，可疑行标出建议
- **开放题代笔 / 职位打标签 / 盯梢过滤**

全链路**默认脱敏**：身份证/电话等发出前打码；只有设置里显式打开「明文送审」才发真值。不配置 LLM 时所有功能离线可用。

### 盯梢源（情报雷达）

工作台「盯梢」卡：粘贴汇总/导航类网站 URL（可设 1/6/12h 间隔）→ 定时抓新公告 → 三层去重合并 → 候选审核区 → 你点头才进台账；LLM 已配置时自动过滤并标注理由。只读情报 + 写候选池：不自动开投递、不自动提交。

## 安全边界（代码层硬约束）

- 永不调用 `form.submit()` / 永不点击最终提交、完整性校验按钮
- 永不触碰 `type=file`（只提示人工上传）
- 协议/承诺类**单个独立 checkbox 永不自动勾选**
- 默认零网络请求；LLM 必须显式配置启用，且默认脱敏；不内置任何统计/遥测
- 分区式站点（中石油）允许点该区「保存教育背景」这类**分区保存**，由适配器白名单驱动，绝不含最终提交
