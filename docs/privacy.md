# 隐私说明

AF-Fill 的设计前提：**你的求职档案是本机数据，不上传、不统计、不遥测**。

## 数据都存在哪

| 数据 | 位置 | 说明 |
|---|---|---|
| 档案 Profile | Tampermonkey 存储 / 工作台 `data/profile.json` | 全部是本机浏览器/本机文件 |
| 设置（含 LLM Key） | 同上 | Key 只存本机 |
| 填充审计 | 本机存储（`af:af.audit`） | 时间/站点/字段/置信度；敏感值打码；可导出/清空 |
| 站点问答记忆 | 本机存储（按域名分桶） | 不进 Profile |
| 台账/盯梢候选 | 工作台 `data/ledger.json`、`data/watch/` | 本机文件 |

仓库里**没有**真实档案：`profile/profile.json`、`driver/config.json` 已被 `.gitignore` 排除；
内置 SEED 与全部示例数据均为虚构人物「李雷」；CI 会对仓库做密钥/PII 扫描（`scripts/check_secrets.py` + gitleaks）。

## 唯一会联网的路径：你自己配置的 LLM

不配置 LLM 时，脚本/工作台**零网络请求**（无 fetch/XHR、无外链字体、无统计）。

启用 LLM 后，以下内容会发送到**你自己填写的** Base URL：

| 场景 | 发送内容 | 默认脱敏 |
|---|---|---|
| AI 扫描映射 | 控件标签/类型/选项文本 + 档案键值表（`mapDigest`） | ✅ 身份证/电话打码 |
| AI 复核 | 待填行的标签 + 值 | ✅ 同上 |
| 开放题代笔 | 你粘贴的 JD 文本 + 档案要点 | ✅ 同上 |
| 职位打标签/盯梢过滤 | 职位页/公告文本 | —（不含档案） |

- 脱敏开关：「明文送审」默认**关**；打开后才会把身份证/电话原样发出
- 使用第三方 API 即等于把上述内容交给该服务商，请自行评估其隐私政策；本地 Ollama 则完全不出本机
- 脚本不内置任何 `@connect`；Tampermonkey 首次调用会弹「允许该域名」，自行确认

## 不要提交什么

- 提 Issue / PR 时别粘贴：真实档案、身份证、API Key、含私人链接的截图
- `python scripts/check_secrets.py` 会扫描「词表（本地）+ 手机号/QQ邮箱/本机用户目录正则」；发布前请把真实信息加入 `tools/sanitize.local.json`（已 gitignore）

## 目标网站侧

- 脚本只在**你的浏览器里**操作你已经打开的页面，与普通手工填写等价
- 不绕过验证码、不绕过登录风控、不自动提交、不自动上传文件
- 使用即表示你自行遵守目标网站的条款；请勿用于批量滥用
